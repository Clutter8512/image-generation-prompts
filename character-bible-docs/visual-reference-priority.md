VISUAL REFERENCE PRIORITY

The supplied visual reference depicts the canonical visual identity of the character described in the accompanying written character specification.

Use the visual reference together with the written character specification. The two sources are complementary:

1. The visual reference is the primary guide for the character's exact facial identity, facial proportions, eye construction, hairstyle shape and length, body proportions, recurring accessories, and overall recognizable appearance.

2. The written specification clarifies which visual traits are canonical and should remain stable when details in the reference are ambiguous.

3. The scene prompt controls the new clothing, pose, activity, expression, environment, composition, camera angle, and lighting unless it explicitly states otherwise.

Depict the SAME recurring fictional adult character shown in the reference, transferred into the requested new scene. Do not create a merely similar character or redesign the character to fit a generic archetype.

Do not copy incidental elements from the reference unless requested by the scene. In particular, do not automatically copy the reference image's pose, everyday clothing, background, furniture, environment, composition, or lighting.

If the scene specifies different clothing, replace the reference outfit while preserving the character's underlying body proportions and visual identity.

Preserve the canonical identity anchors established by the written character specification and visual reference, including:

- Exact facial identity and facial proportions.
- Eye design and eye color.
- Hair color, length, construction, and recurring accent details.
- Established bangs, face-framing locks, or other signature hairstyle elements.
- Canonical hair accessories.
- Recurring jewelry or other small accessories.
- Established adult body proportions.
- Distinctive visual personality and expression language.

Treat the reference image or reference sheet as CHARACTER IDENTITY information rather than as a scene to reproduce.

Where the written character specification, visual reference, and scene prompt address different aspects of the image, combine them rather than allowing one to erase the others.

Priority for interpretation:
CANONICAL CHARACTER IDENTITY -> EXPLICIT SCENE REQUIREMENTS -> INCIDENTAL REFERENCE DETAILS.

The finished image should look unmistakably like the same established character placed into a new situation, not like a newly designed character merely inspired by the reference.
